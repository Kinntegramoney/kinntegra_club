<analysis>**original_problem_statement:**
The user is building a B2B platform for brokers to manage client investments in NCDs and Real Estate. The core of the application involves parsing password-protected CAS PDFs for portfolio analysis and generating detailed Excel reports with complex financial calculations (FIFO, XIRR, TDS).

Throughout this session, the user requested several significant features and fixes:
1.  **Prepayment Enhancement**: When a principal prepayment occurs, the system must calculate and display the percentage prepaid, notify the client via email, and update all related financial data, including future cashflows and reinvestment opportunities.
2.  **Real Estate Passport Details**: For clients investing in real estate, a new feature was required to upload and manage passport details (number, issue/expiry dates, document upload). This information should be visible in the client's real estate portfolio.
3.  **CAS Analysis Report Overhaul**:
    *   **Sold Units Tab**: Create a new tab in the generated Excel report dedicated to fully sold/redeemed mutual fund units, showing the actual purchase price and calculated profit/loss. This tab must also include Financial Year and Capital Gain Treatment (Long/Short Term) for each transaction.
    *   **Filter MF Transactions**: The main MF Transactions tab should be cleaned up to only show active holdings, removing all redemption transactions and purchase entries that have a zero unit balance.
    *   **Correct NAV Calculation**: Fix a bug where the Current NAV was incorrectly showing as 1. The system must now fetch the NAV for the day *before* the CAS statement date from an external API if it's not correctly parsed from the PDF.
4.  **Analysis Dashboard**: Create a new visual dashboard on the Analysis page to display a summary of the data retrieved from the CAS file.
5.  **Reinvestment Tagging Logic**: Enhance the Reinv Tag page by adding a Portfolio category dropdown (e.g., Wealth, Tax, Bonds). An entry should only be considered complete if both a reinvestment tag and a portfolio category have been selected.
6.  **Database Reset Utility**: Create a secure but user-friendly way for a non-technical user to clear all transactional data (clients, trades, bonds) from the production database while preserving broker login accounts.
7.  **Bond Creation Cleanup**: Remove the Credit Rating field from the bond creation form and the bulk upload process.
8.  **Bug Fix**: A bug was preventing real estate opportunities from appearing on the Opportunities page.
